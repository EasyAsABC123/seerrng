## Google Play

**App name:** SeerrNG

**Short description:** Request media from a SeerrNG server you configure and control.

**Full description:**

SeerrNG is a mobile client for connecting to your own SeerrNG server.

Add one or more server addresses, choose which server to open, and sign in to the server you manage. The app keeps each saved server's web session on your device and opens that server directly; Snapetech does not provide a hosting service or SeerrNG account.

You need access to a working SeerrNG server to use the app. Server availability, login, media catalog, and server-side data are controlled by the server operator.

HTTPS is recommended. The app warns before saving an HTTP address because HTTP does not encrypt sign-in details or session cookies in transit.

If the capped-preview build is selected, it includes 20 successful server sessions per installation. Google Play manages any optional lifetime unlock shown in the Play version. Availability and localized price appear in Google Play before purchase.

## Apple App Store

**Name:** SeerrNG

**Subtitle:** Your SeerrNG server companion

**Promotional text:** Connect to the SeerrNG server you choose, manage multiple saved servers, and continue your session in the app.

**Description:**

SeerrNG connects to a SeerrNG server that you configure and control.

Save more than one server address, choose which server to open, and sign in to that server. Each saved server keeps a separate web session on your device. Snapetech does not host your server or provide a SeerrNG account.

A working SeerrNG server and permission to access it are required. The server operator controls availability, authentication, catalog content, and server-side data retention.

HTTPS is recommended. If you choose an HTTP address, the app explains that sign-in details and session cookies are not encrypted in transit before it saves the address.

The capped-preview build includes 20 successful server sessions per installation. Any optional lifetime unlock is processed by Apple and uses the localized price shown before purchase.
