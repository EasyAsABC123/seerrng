SeerrNG now has a native Bindery service for ebook, audiobook, or mixed-format requests. Bindery handles acquisition while SeerrNG tracks request status and scans imported books for availability. Requester ownership is used when the Bindery instance advertises support; otherwise the configured API key account owns the added book.
