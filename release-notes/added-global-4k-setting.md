Administrators can now disable 4K support globally in Settings → Main. Turning it off hides movie and TV 4K request, issue-reporting, and availability options, blocks new 4K requests and issue reports, and stops future scans from recording 4K separately. Existing records and Radarr/Sonarr server classifications are preserved.
